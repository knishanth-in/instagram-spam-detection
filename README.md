# AI-Based Instagram Spam Detection Using NLP and Machine Learning

An intelligent spam detection system for Instagram messages and comments using Python, Flask, Scikit-learn, and Natural Language Processing (NLP).

## 📌 Project Overview

This project is designed to detect spam messages and comments on Instagram using Machine Learning and NLP techniques. The system analyzes text input and classifies it as either **Spam** or **Not Spam**.

The application provides a simple web interface built with Flask where users can enter messages and instantly receive prediction results.

* Natural Language Processing (NLP) based text preprocessing

## ⚙️ Installation

### 1️⃣ Clone the repository

```bash
git clone https://github.com/knishanth-in/instagram-spam-detection.git
```

### 2️⃣ Navigate to project folder

```bash
cd instagram-spam-detection
```

### 3️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the application

```bash
python app.py
```

## ▶️ Usage

1. Open the web application in your browser.
2. Enter an Instagram message or comment.
3. Click on Predict.
4. The system will classify the message as Spam or Not Spam.
